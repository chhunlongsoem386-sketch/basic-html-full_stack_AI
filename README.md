# Expense Tracker

A beginner-friendly Expense Tracker dashboard built with HTML5 and Tailwind CSS v4 Play CDN.

## Open the project

1. Open the `expense-tracker` folder in VS Code.
2. Open `index.html`.
3. Choose **Open with Live Server**.
4. Keep an internet connection so the Tailwind Play CDN can load.

## Features

- Monthly Summary: Balance, Income, and Expenses
- Styled Add an expense form
- Recent Transactions table
- Responsive design for desktop and mobile
- Horizontal table scrolling on small screens

## Technologies Used

- HTML5
- Tailwind CSS v4 Play CDN
- Git and GitHub

## Project Status

This is a static learning project.
The expense form does not save data yet.
Transactions are sample data only.
